# Parameter registry

Initial M1 inventory, 2026-10-01. Not a runnable baseline configuration. Blank values and bounds mean unknown, never zero. No probability distribution has been justified.

Read admission_status before using any row. Adopted assumptions come from M0; historical_not_adopted values are quarantined primer audit targets; gap_blocks_dependent_claim rows require evidence or explicit scenario ranges. Organ rows distinguish baseline, maintenance and specified-function demand. A deficit threshold is not assumed to exist as a single transferable biological constant.

Source aliases: m0protocol = docs/research-protocol.md; primer_archive = docs/archive/primer-pre-m1-2026-10-01.md with stable claim IDs in docs/claim-evidence-ledger.csv. Published parameter sources will use bibliography keys as extraction proceeds.

The placeholder network families must be expanded into individual paths/compartments when M2 chooses equations. They are not a complete final parameter list. Numerical bounds are intentionally unassigned rather than copied from incompatible physiology. See docs/m0-to-m1-traceability.md for admission rules.


Follow-up: 160 records, including E008–E010 brain baseline candidates. Their lower_bound/upper_bound fields contain observed sample ranges, explicitly marked in uncertainty_notes, not approved scenario bounds or population limits. SD does not imply a normal distribution. The 118 gap rows remain blocked. Proposed treatments in docs/m1-review-decisions.md are not adopted settings.

primer-arithmetic-audit.json is generated by scripts/audit_primer_math.py; it audits historical assumptions, not a pump specification. Source alias primer_math_audit refers to docs/primer-arithmetic-audit.md.
